오늘의게임 - 아이 교육 신규 콘텐츠 2종 통합 안내
====================================================

포함된 게임
-----------
1. games/edu-vowel-zoo/index.html    → 모음 놀이터 (URL 예상: /games/edu-vowel-zoo/, 레벨 1 추천)
   - 기존 "자음 동물원"과 짝을 이루는 모음 학습 게임
   - 아/야/어/여/오/요/우/유/으/이 10개 기본 모음(음절)을 다룸
   - Web Speech API(speechSynthesis)로 소리를 직접 들려주고, 3지선다로 그림 찾기
   - 정답 시 별 획득, 오답은 감점 없이 다시 듣고 재시도하는 방식 (아이 대상이라 실패 압박 없음)

2. games/edu-letter-trace/index.html → 글자 따라쓰기 (URL 예상: /games/edu-letter-trace/, 레벨 1~2 추천)
   - 기존 8개 게임 중 유일하게 없던 "쓰기" 영역을 채우는 콘텐츠
   - 자음 14개 + 모음 10개, 총 24개 글자를 캔버스에 손가락/마우스로 따라쓰기
   - 완성할 때마다 스티커(⭐️) 획득, localStorage에 누적 저장
   - 실패 판정 없이 자유롭게 연습하는 형태 (필순 인식 없음, 순수 트레이싱)

적용 방법
---------
기존 사이트가 /games/edu-jamo-zoo/ 처럼 "폴더 + index.html" 구조라면,
이 games 폴더 안의 2개 폴더를 기존 프로젝트의 games 폴더에 그대로 복사해 넣으면 됩니다.

Next.js/React 컴포넌트 구조라면 기존 교육 게임 파일(예: edu-jamo-zoo 컴포넌트) 하나를
Cursor에서 보여주시면 동일한 패턴으로 다시 변환해 드릴 수 있습니다.

아이 교육 카테고리 추가 예시 (레벨 순서 참고):
  [모음 놀이터레벨 1 · 모음플레이](/games/edu-vowel-zoo/)   ← 자음 동물원 옆에 배치 추천
  [글자 따라쓰기레벨 1~2 · 쓰기플레이](/games/edu-letter-trace/)

참고 사항
---------
- 외부 의존성은 구글 폰트(Jua, Gowun Dodum) CDN 링크 하나뿐입니다.
- 모음 놀이터의 소리 재생은 기기의 한국어 TTS 음성에 의존합니다 (대부분의 모바일 브라우저에서 기본 지원).
- 글자 따라쓰기의 스티커 수·완료한 글자 목록은 localStorage에 저장됩니다.
- 다음 교육 콘텐츠 후보로 "받침 맞추기(Lv5)"도 논의했었는데, 필요하시면 이어서 만들어드릴게요.
