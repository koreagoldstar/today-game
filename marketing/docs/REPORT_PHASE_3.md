## 확인하지 못한 것

- **GitHub Actions 러너에서 실제로 녹화한 것은 아님.** 2D 두 게임은 이 PC 에서 같은 조건(SwiftShader)으로 초당 22~27장. 러너 CPU 가 더 느리면 기준(20장) 아래로 떨어질 수 있음 — 그러면 실패로 남음(가짜 성공 없음). PHASE 5 에서 실제 러너로 확인.
- **3D 재고 올리기** (Vercel Blob + Redis) · **Windows 작업 스케줄러 등록**은 열쇠가 필요해 PHASE 5 로 미룸. 재고 규칙은 가짜 Redis 시험으로만 확인.
- 원본 크기가 큼 (3D 45~62MB, 2D 12~24MB). 재고로 올릴 때는 압축해서 올려야 Blob 무료 한도(1GB)에 맞음 — PHASE 5.
- 인형뽑기는 판마다 획득이 보장되지 않음 (이번 60초 1번, 그 전 48초 0번). 하늘섬 클립에는 구름 속이라 화면이 하얀 몇 초가 있음. 어느 구간을 쓸지는 PHASE 4 하이라이트 · 검수에서.
- 인형뽑기 첫 몇 초에 처음 하는 사람용 안내 말풍선이 보임 (실제 화면 그대로).
- 드래곤 석상은 모험 1지역을 `adv.start(0, { retry: true })` 로 시작 — 사이트 점검 스크립트와 같은 길이며, 입구 석상 퍼즐은 건너뜀 (게임 규칙 변경 아님, 프로필 `note` 에 적음).
