# 관리자 사용 설명서 (텔레그램 + 웹)

하루 할 일은 **텔레그램에 온 승인 요청을 보고 버튼을 누르는 것**뿐입니다. 웹 관리자는 같은 일을 더 넓은 화면에서 하고, 편성표 · 게임 설정 · 성과를 봅니다.

**두 곳은 같은 자료 · 같은 규칙**입니다. 텔레그램과 웹에서 동시에 눌러도 한 번만 반영되고, 늦게 누른 쪽은 "그사이 내용이 바뀌었습니다"가 나옵니다.

## 하루 흐름

| 시각(서울) | 일 |
|---|---|
| 08:07 쯤 | 스토리 1개(운세 · 챌린지 · 재활용 중 그날 차례) + 피드 1개(요일 편성표)를 만들어 **승인 요청** |
| 08:30 | 승인된 스토리 게시. 운세 · 챌린지는 **그날만** 올라가고, 늦게 승인하면 10분 뒤 올라감 |
| 19:00 | 승인된 피드 게시 |
| 30분마다 | 텔레그램 버튼 처리 · 게시 · 지표 모으기 |
| 월요일 아침 | 지난주 요약이 텔레그램으로 옴 |

**요일 편성표 (기본):**

| 월 | 화 | 수 | 목 | 금 | 토 | 일 |
|---|---|---|---|---|---|---|
| 지난주 랭킹 (기록 모자라면 게임 릴스) | 게임 릴스 | 상식퀴즈 캐러셀 | 게임 릴스 | 신작 (없으면 게임 릴스) | 게임 릴스 | 상식퀴즈 |

웹 → 편성표에서 바꿉니다.

**지켜지는 규칙:**
- **승인하지 않으면 어떤 채널에도 올라가지 않습니다.** 승인 뒤 문구 · 채널 · 시각을 바꾸면 승인이 풀리고 다시 승인해야 합니다.
- 승인 대기 **72시간**이 지나면 "기한 지남"으로 정리됩니다. 운세 · 챌린지는 그날 자정이 지나면 정리됩니다.
- 승인 대기가 3개 쌓이면 새로 만들지 않습니다 (설정에서 바꿀 수 있음).

## 텔레그램

승인 요청 하나에 다음이 옵니다:
- 영상, 또는 사진(캐러셀은 앨범)
- 정보: 제목 · 버전 · 채널 · 게시 예정 시각 · 검수 결과
- 채널별 문구, 퀴즈면 "게시 뒤 첫 댓글(정답)"

| 버튼 · 동작 | 하는 일 |
|---|---|
| ✅ 승인 | 다음 빈 게시 자리로 예약 |
| ❌ 반려 | 사유를 답장으로 적으면 반려 |
| ✍️ 문구 다시 만들기 | AI · 틀로 문구를 새로 (다음 실행에서) |
| 🎬 다시 제작 | 영상 · 이미지부터 새로 |
| ☑/☐ 채널 이름 | 채널 켜고 끄기 (그 형식을 받는 채널만) |
| 🗑 게시 취소 | 올리지 않음 |
| 승인 요청 메시지에 **답장으로 새 문구** | 인스타 문구 직접 수정 (해시태그는 `#` 로 시작하는 마지막 줄) |

그 밖의 알림:
- 게시 완료(모의면 "(모의)")
- 게시 실패(채널 · 이유)
- 제작 실패
- 기한 지남
- 인스타 · Threads 토큰 만료 · 갱신 실패
- 주간 요약

## 웹 관리자 `/mkt-admin/`

`MKT_ADMIN_KEY` 로 로그인합니다. 이 기기에서 7일 동안 기억합니다. 틀린 키를 15분에 5번 넣으면 15분 잠깁니다.

| 메뉴 | 할 수 있는 것 |
|---|---|
| 오늘 현황 | 상태별 개수, 오늘 콘텐츠, 다음 게시, 최근 자동 실행 |
| 승인 대기 | 미리 보기 · 승인(시각 지정 가능) · 반려 · 인스타 문구 고치기 · 문구 다시 · 다시 제작 · 채널 · 취소 |
| 게시 일정 | 예약된 것: 시각 변경 · 채널 변경 · 취소 (바꾸면 다시 승인) |
| 게시 완료 | 채널별 결과 · 게시물 주소 · 첫 댓글 결과 |
| 실패 내역 | 실패 · 반려 · 취소 · 기한 지남과 이유 |
| 게임별 설정 | 게임마다 홍보 켜기/끄기 · 녹화 프로필 · PC 녹화 재고 · 마지막 게시 |
| 편성표 | 요일별 피드 순서 · 스토리 순서 · 게시 시각 · 기본 채널 · 승인 대기 상한 · 다시 홍보 간격 · 사이트 클릭 세기 |
| 채널 연결 | 채널별 실제/모의 · 상태 · 토큰 남은 날 (30분마다 갱신) |
| 성과 | 게시물별 지표(실제 게시만) · 사이트 클릭 · 주간 요약 |
| 로그 | 자동 실행 · 웹에서 한 일 기록 |

## 자주 하는 일

- **오늘 하나 더 만들기:** GitHub → Actions → mkt-produce → Run workflow (`force` 켜기, 게임 지정 가능)
- **특정 게임을 당분간 빼기:** 웹 → 게임별 설정 → "홍보함" 끄기
- **게시를 전부 멈추기:** GitHub Variables 의 `CHANNEL_MODE_*` 를 `mock` 으로 (그 뒤로는 모의 게시만)
- **인스타 토큰 다시 연결:** `CHANNEL_SETUP.md` §2

## 알아 둘 것

- 영상은 **실제 게임 플레이**, 숫자는 **사이트의 실제 기록**만 씁니다.
  - 랭킹 닉네임은 가립니다 (`삐*이`).
  - 퀴즈 정답은 이미지 · 캡션이 아니라 첫 댓글에 넣습니다.
- **모의(Mock) 게시는 아무 데도 올라가지 않습니다.** 알림에 "(모의)"라고 표시됩니다.
- 3D 게임 녹화는 이 PC 가 켜져 있을 때만 쌓입니다. 재고가 없으면 다른 게임 · 유형으로 넘어갑니다.
