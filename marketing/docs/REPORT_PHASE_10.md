# PHASE 10 보고 — 성과 수집 · 유입 측정 · 주간 요약 · 게임 고르기 가중치

날짜: 2026-11-10 · 브랜치 `feature/marketing` · 시험 89/89 통과

## 만든 것

- **게시물 지표** (`core/insights.js collectInsights`, 30분마다 게시 실행에서)
  - 게시 **1 · 3 · 7일 뒤** 플랫폼이 주는 지표를 저장합니다 (`doc.insights[채널]`). 놓친 시점은 한 번에 채웁니다.
  - **실제(live) 게시만** 모읍니다. 모의 게시는 지표가 없으므로 모으지도, 만들지도 않습니다. 실패하면 기록하지 않고 다음 실행에서 다시 합니다.
  - 채널별 지표:
    - 인스타: views · reach · likes · comments · saved · shares · total_interactions (지원 안 되는 지표는 하나씩 다시 물어 빠짐)
    - Threads: views · likes · replies · reposts · quotes · shares
    - YouTube: 공개 통계(조회 · 좋아요 · 댓글)
    - Facebook: API 가 주는 그대로
- **팔로워 수**: 하루 한 번 `followers:{채널}:{날짜}` 에 저장합니다 (실제 연결된 채널만).
  - 인스타 `followers_count`, Threads `threads_insights followers_count`, Facebook `followers_count`, YouTube 구독자 수 (숨김이면 없음).
- **유입 측정 (결정 4 안 A)** — `api/mkt-go.js` (새 함수, 사이트 함수 9개째)
  - 링크 → 클릭을 세고 → 같은 사이트 주소로 302 이동합니다.
  - **사이트 안 경로로만** 보냅니다 (`//다른곳` · `\` · `https:` · `javascript:` 는 홈으로).
  - 링크 미리보기 봇(facebookexternalhit · 텔레그램 · 카카오 등)은 세지 않습니다.
  - 세기가 늦어도 이동은 0.8초 안에 합니다.
  - 설정 `trackClicks`(기본 **꺼짐**)를 켜면 Threads · Facebook · YouTube 문구의 링크가 `/api/mkt-go?c=…&ch=…&to=…` 가 됩니다.
  - 인스타는 캡션에 링크가 없어 해당하지 않습니다 (프로필 링크).
  - **mkt-go 를 운영에 배포하기 전에는 켜지 마세요.** 켜면 링크가 404 가 됩니다. 웹 관리자 편성표에서 켜고 끕니다.
- **주간 요약**: 월요일 첫 게시 실행에서 지난주(월~일)를 한 번 보냅니다 (`report:sent:{주}`). 텔레그램과 웹 관리자 "성과"에 나옵니다.
  - 내용: 실제 · 모의 게시 수, 조회 합계, 가장 많이 본 콘텐츠, 클릭, 팔로워 증감, 만든 · 반려 · 기한 지남 · 실패 수.
  - 직접 보내기: `node marketing/run.js weekly [--monday YYYY-MM-DD]`.
- **게임 고르기 가중치**: 게임별 평균 조회 수 ÷ 전체 평균을 **0.5~2배**로 묶어 점수에 곱합니다 (`settings.weights`).
  - 실제 조회 수가 있는 게임만 적용합니다. 14일 규칙 · 신작 우선 순서는 그대로 유지됩니다.

## 실제 실행해서 확인한 것

- 실제 저장소로 `run.js publish`: 지표 수집 단계가 돌았고 결과는 `[]` 입니다 (실제 게시가 아직 없음 — 모의 게시는 일부러 건너뜀).
- 실제 텔레그램으로 주간 요약 발송: `run.js weekly --monday 2026-11-09`
  - 2026-W45(11/2~11/8) 요약이 텔레그램에 갔습니다. 그 주에는 아직 콘텐츠가 없어 0건으로 정직하게 보고합니다.
  - 다음 주(W46) 요약은 2026-11-16(월) 게시 실행이 자동으로 보냅니다 (master 병합 뒤 예약 실행).
- 시험 4개 추가:
  - 1·3·7일 시점, 모의 제외, 같은 시점 한 번만, 놓친 시점 한 번에, 실패 뒤 다시.
  - 가중치 2배 · 0.5배 상한과 게임 순위 반영.
  - 팔로워와 주간 요약 문구 · 한 번만 · 월요일만.
  - 클릭 링크(설정 꺼짐/켜짐), 열린 리다이렉트 6가지 차단, 봇 제외, 키 앞머리.
