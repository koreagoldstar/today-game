  - 녹화 프로필 자체는 저장소 파일이라 보기만 합니다.

- 채널 연결: 실제로 게시하는 Actions 환경에서 본 mock/live · 상태를 보여 줍니다.

- 로그: 자동 실행 · 웹에서 한 일 기록.

**보안**
- 키는 `MKT_ADMIN_KEY` (24자 이상, Vercel 환경 변수에만). 모니터실과 같은 방식으로 로그인하면 7일 토큰이 나옵니다.
- 저장소에는 토큰의 sha256 만 저장합니다. 틀린 키는 같은 IP 15분 5번, 전체 1시간 30번이면 잠깁니다.
- 쿠키 없이 `Authorization` 헤더로만 인증하므로 다른 사이트가 관리자 대신 요청을 보낼 수 없습니다 (CSRF 없음).
- 화면의 글자는 모두 `textContent` 로 넣습니다 (문구에 HTML 이 섞여도 실행 안 됨).

## 고친 것

- **설정 저장 방식:** 전체 대신 **바꾼 값만** 저장합니다. 전에는 전체를 저장해서 PHASE 7 에서 바꾼 기본값(스토리에 재활용 추가)이 운영에 반영되지 않고 있었습니다.
  - 운영 저장소의 설정 복사본을 확인했습니다. 관리자가 바꾼 값은 없었고 옛 기본값뿐이어서 지웠습니다. 이제 기본값을 따릅니다.
