# 시험 계획 (PHASE 1)

원칙
- **Mock 과 live 결과를 따로 적습니다.** 실제 계정이 없으면 Mock 으로 끝까지 확인하고 "live 연결 대기"로 표시합니다.
- 테스트는 운영 Redis · 운영 사이트에 쓰지 않습니다. 저장소는 가짜 Redis(Upstash REST 흉내), 녹화는 로컬 서버 + `/api/**` 가짜 응답 + 서비스워커 차단.
- 운영 데이터를 읽는 확인은 읽기 전용 GET 만, 닉네임은 기록에 남기지 않습니다.
- 실제로 돌려 본 것만 "통과"로 적습니다.
