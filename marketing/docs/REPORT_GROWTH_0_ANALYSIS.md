# 성장 최적화 0단계 — 기존 자동화 분석 보고 (2026-11-28)

지시: "Today Game 인스타그램 자동 홍보 시스템 성장 최적화 프로젝트". 원칙대로 **개발 전에** 지금 구조와 실제 상태를 확인했다.
"확인함" = 이번에 코드 · 운영 데이터 · API 를 직접 보고 확인한 것. 추정은 따로 적는다.

## 가장 먼저 알아야 할 것 — 지표 권한이 없다

- 인스타 토큰 권한(2026-11-28 `/me/permissions` 실제 조회): `instagram_basic` · `instagram_content_publish` · `instagram_manage_comments` · `instagram_manage_messages` · `public_profile`.
- **`instagram_manage_insights` 가 없다.** 그래서 게시물 지표(조회 · 도달 · 공유 · 저장 · 평균 시청 시간)와 계정 지표(프로필 방문 · 팔로우 · 링크 클릭)는 API 가 `(#10) Application does not have permission` 으로 거절한다 (오늘 릴스 1개 · 계정 지표로 실제 확인).
- 지시서 5 · 6 · 7 · 8 · 11장(성과 수집 · 분석 · 학습 · 대시보드 · 30일 실험)은 **이 권한이 있어야 실제 데이터로 돌아간다.** 지금은 앱 화면의 숫자(조회 418 · 프로필 방문 11)를 API 로 가져올 수 없다.
- API 로 읽히는 팔로워 수는 **4명**이다 (지시서의 14명은 앱 화면 기준이거나 다른 기간 값일 수 있음 — 확인 필요).
- 해결: Meta 비즈니스 설정 → 시스템 사용자 → 토큰 다시 만들기에서 `instagram_manage_insights` 를 체크. **관리자 계정으로 직접 해야 하는 일**이다 (토큰 화면은 팝업이라 제가 열 수 없음, 2026-11-11 연결 때와 같음).
