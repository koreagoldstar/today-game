팝팝 방울 소개

하늘로 떠오르는 반짝 방울을 톡톡 터뜨려 목표 점수를 채우는 50단계 탭 게임입니다. 작은 방울과 금빛 방울일수록 점수가 높고, 쉬지 않고 이어서 터뜨리면 콤보로 점수가 불어나요. 까만 방울은 시간을 깎으니 조심!

플레이 방법

떠오르는 방울을 탭해서 터뜨리세요. 제한 시간 안에 목표 점수를 채우면 스테이지 클리어이고, 남은 시간은 보너스 점수가 돼요. 까만 방울을 누르면 4초가 줄고 콤보가 끊겨요.

자주 묻는 질문

어떤 방울이 점수가 높나요?
금빛 방울과 작은 방울일수록 점수가 높아요. 쉬지 않고 이어서 터뜨리면 콤보 배수가 붙어요.
까만 방울을 누르면 어떻게 되나요?
