    • 자석을 켜면 둥근 범위 안의 금속이 움직여요. 가까울수록 세고, 무거운 것은 덜 움직여요.

    • 자석을 끄면 붙어 있던 물건이 떨어져요. 끌려오는 중에 끄면 그대로 날아가요!

      사이트로

      자석 대소동 소개

      고장 난 공장에서 정비 로봇 마그가 자석으로 사고를 해결하는 물리 퍼즐 어드벤처 게임입니다. 마그의 자석을 켜고 끄고, N극과 S극을 바꿔 가며 물건을 끌어당기거나 밀어내요. 철은 세게, 합금은 약하게 붙고, 나무와 고무는 붙지 않아 몸으로 밀어야 해요. 자석 블록은 다른 극이면 끌려오고 같은 극이면 밀려나요. 누름 스위치와 문, 컨베이어, 스프링, 움직이는 발판, 리프트, 레버, 벽에 붙은 전자석이 이어져 물건 하나가 스위치를 누르면 다른 장치가 움직이는 연쇄가 일어나요. 물체는 무게와 마찰, 튕김을 계산하는 물리 엔진으로 움직이고, 무거운 철 상자는 끌 때 마그가 천천히 걸어요. 자석과의 첫 만남부터 극성 바꾸기, 철구 대소동, 컨베이어 혼란, 스프링 실험, 에너지 위기, 공장 연쇄 사고, 코어 세 개로 깨우는 거대 자석 장치까지 스테이지 12개가 있고, 모든 스테이지는 게임과 같은 규칙으로 돌아가는 자동 풀이로 깰 수 있는 것을 확인했어요. 깨면 별 1개, 정한 시간 안이면 별 2개, 숨은 기어 찾기 · 자석 적게 켜기 · 극 적게 바꾸기 · 에너지 남기기 같은 스테이지별 목표를 이루면 별 3개예요. 숨은 기어를 모으면 마그의 색을 바꿀 수 있고, 날짜마다 누구나 같은 판을 푸는 오늘의 자석 실험도 있어요.

      플레이 방법

      컴퓨터에서는 ← → 또는 A · D 로 걷고, ↑ · W · 스페이스로 점프해요(길게 누르면 더 높이). K(또는 J)는 자석 켜기 · 끄기, L(또는 Q)은 N극 · S극 바꾸기, E(또는 Enter)는 레버 조작이에요. P 나 Esc 는 일시정지, R 은 다시 하기예요. 휴대폰과 패드에서는 화면 왼쪽 아래 ◀ ▶ 로 걷고, 오른쪽 아래 큰 버튼으로 점프 · 자석 · 극 바꾸기 · 레버를 눌러요. 위쪽에는 스테이지 이름과 목표, 자석 상태, 지금 극, 에너지, 시간이 보여요. 자석에 붙은 물건은 마그 곁에 붙어 따라다니고, 칸 위에서 자석을 끄면 쏙 들어가 딸깍 고정돼요.

      자주 묻는 질문

      어떤 물건이 자석에 붙나요?
      철(Fe)은 세게, 합금은 약하게 붙어요. 나무와 고무는 붙지 않아서 몸으로 밀어야 해요. N · S 가 적힌 자석 블록은 마그의 극과 다르면 끌려오고, 같으면 밀려나요.
      에너지는 무엇인가요?
      에너지가 있는 스테이지에서는 자석을 켜 둔 동안 에너지가 줄고, 다 쓰면 자석이 저절로 꺼져요. 꼭 필요할 때만 켜고 바로 끄는 것이 요령이에요.
      별은 어떻게 받나요?
      출구로 나가면 별 1개, 정한 시간 안에 깨면 별 2개, 스테이지마다 정한 특별 목표(숨은 기어 · 자석 적게 켜기 · 극 적게 바꾸기 · 에너지 남기기)까지 이루면 별 3개예요. 시작 안내와 결과 화면에 기준이 나와요.
      오늘의 자석 실험은 무엇인가요?
      서울 날짜마다 정해진 짧은 실험 판이에요. 같은 날에는 누구나 같은 판을 풀고, 깬 시간이 이 기기에 최고 기록으로 저장돼요. 원하면 결과 화면에서 이름을 적어 오늘 순위에 직접 올릴 수 있어요.
      기록은 어디에 저장되나요?
      스테이지 별 · 최고 기록 · 숨은 기어 · 꾸미기는 이 기기의 브라우저에만 저장돼요. 순위는 결과 화면에서 직접 이름을 적어 올릴 때만 서버에 보내져요.
