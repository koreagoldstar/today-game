    숫자야구 소개
    
  
    숨어 있는 숫자 3개(또는 4개)를 10번 안에 맞히는 추리 게임입니다. 숫자를 던지면 숫자와 자리가 모두 맞은 개수는 스트라이크(S), 숫자는 있지만 자리가 다른 개수는 볼(B)로 알려 줘요. 하나도 없으면 아웃! 매일 바뀌는 오늘의 숫자야구는 모두 같은 문제라서 친구와 몇 번 만에 맞혔는지 겨룰 수 있어요.
    
  
    플레이 방법
    
  
    1부터 9까지 서로 다른 숫자를 골라 던지세요. 결과를 보고 어떤 숫자가 어느 자리에 있는지 좁혀 가면 돼요. 위쪽 메모 칸을 누르면 없는 숫자(✕)와 있는 숫자(●)를 표시해 둘 수 있고, 아웃이 나온 숫자는 자동으로 ✕ 표시돼요. 컴퓨터에서는 숫자 키로 입력하고 Enter 로 던질 수 있어요.
    
  
    자주 묻는 질문
    
  
    
    
    0 이나 같은 숫자도 나오나요?
    
    
    아니요. 정답은 1부터 9까지 서로 다른 숫자로만 만들어져요.
    
    
    친구와 같은 문제로 할 수 있나요?
    
    
    오늘의 숫자야구는 모두 같은 문제예요. 연습 판도 결과 화면의 도전장을 보내면 친구가 똑같은 문제로 시작해요.
