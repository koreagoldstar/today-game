애플 스네이크 소개

반짝이는 사과를 먹으며 쑥쑥 자라는 스네이크 게임입니다. 뱀이 칸을 뚝뚝 뛰지 않고 매끄럽게 미끄러지고, 먹은 사과가 불룩하게 몸을 타고 내려가요. 햇살 초원, 벚꽃 언덕, 단풍 숲, 눈 덮인 들판, 반딧불 밤까지 테마 5가지에 50 스테이지가 있고, 스테이지마다 돌 배치와 속도가 달라요. 시간이 지나면 사라지는 황금 사과, 잠깐 느려지는 파란 열매, 꼬리를 줄여 주는 버섯도 나와요. 모든 스테이지는 길찾기 봇으로 깰 수 있는지 확인했어요.

플레이 방법

휴대폰은 화면을 밀어서, 컴퓨터는 방향키나 WASD 로 조종해요. 칸을 막 떠난 참에 누르면 바로 꺾고, 빠르게 두 번 누른 방향도 차례로 기억해요. 벽이나 돌 바로 앞에서는 잠깐 멈춰 기다려 주니 그때 방향을 바꾸면 살아요. 부딪히면 목숨이 줄고 가운데에서 다시 출발해요. 연속으로 먹으면 콤보로 점수가 커지고, 목숨을 잃지 않고 깨면 별 3개예요. 깬 스테이지까지는 이어하기로 계속할 수 있고, 무한 모드에서는 점점 빨라져요.
